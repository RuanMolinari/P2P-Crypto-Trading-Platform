# Plataforma P2P Solana

Plataforma de intermediação de trocas de criptomoedas peer-to-peer usando contratos inteligentes na rede Solana.

## Funcionalidades
- Registro e conexão de carteira
- Criação e aceitação de ofertas
- Painel administrativo com relatório de lucros

## Tecnologias
- Anchor (Rust)
- React + Vite
- Wallet Adapter (Phantom)
